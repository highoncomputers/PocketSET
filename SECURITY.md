# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

PocketSET is a penetration testing wrapper. Security is a core concern.

If you discover a security vulnerability, please:

1. **Do not** open a public issue
2. Email details to the repository owner via GitHub
3. Include steps to reproduce and potential impact

You should receive a response within 48 hours.

## Responsible Use

This tool is for **authorized security assessments only**. Unauthorized use may be illegal. See the LEGAL DISCLAIMER in the README.
